# Tau SuStaIn figure source data

This package contains compact plotting tables, bundled fsaverage5 surface geometry, the two plotting scripts, and reference exports for the Tau SuStaIn main-text figures.

Run from this directory:

```powershell
python plot_fig_tau_sustain_ap_2.py
python plot_combined_sustain_summary_panel.py
```

Outputs are written to `outputs/`. Required packages are provided by the repository's `figures` optional dependency group.
